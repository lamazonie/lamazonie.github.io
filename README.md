# L'Amazonie · Material complementar dos livros

Site estático publicado no GitHub Pages em https://lamazonie.github.io

- `/teste-falha/` — teste interativo "Que tipo de falha é a sua?" (12 perguntas, três perfis) e download do ebook em PDF (`/teste-falha/ebook/`).
- `/semana/` — "Criativos da semana": relatório semanal para o time de creators e edição (o que vendeu, o que cansou, pedidos de produção, vídeos para assistir e baixar). Dados em `semana/data/` (uma edição por arquivo, `edicoes.json` lista as semanas, `criativos.json` é o catálogo). Mídia em `semana/media/`. Sem números de venda nos arquivos públicos.

Para publicar: Settings → Pages → Source: *Deploy from a branch* → Branch `main`, pasta `/ (root)`.
